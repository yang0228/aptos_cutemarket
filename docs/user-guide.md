# 用户指南

## 什么是 CuteMarket

CuteMarket 是一个去中心化预测市场，部署在 Aptos 区块链上。你可以对现实世界的事件下注，所有资金和赔率都由智能合约管理，没有后端服务器。

## 准备工作

### 安装钱包

推荐使用 [Petra Wallet](https://petra.app/)（Aptos 官方钱包）：

1. 访问 https://petra.app/ 下载浏览器扩展
2. 创建新钱包，安全保存助记词
3. 在设置中切换到 **Testnet**（测试网）

### 获取测试币

访问 https://aptos.dev/network/faucet 输入你的地址领取。

## 连接钱包

1. 打开 CuteMarket 网站
2. 点击右上角 **Connect Wallet** 按钮
3. 选择 Petra Wallet
4. 在钱包弹窗中点击 "Connect" 授权连接
5. 连接成功后，右上角显示你的钱包地址

## 浏览预测市场

首页显示所有可参与的预测市场：

- **搜索** — 按名称搜索市场
- **分类筛选** — 体育、加密货币、政治、娱乐、科技、其他
- **排序** — 热门（TVL）、最新、即将到期
- **市场卡片** — 显示名称、分类、总池、选项数、状态

无需连接钱包即可浏览所有市场。点击任意市场卡片进入详情页。

## 交易（买入/卖出份额）

### 操作步骤

1. 在市场详情页，左侧面板为交易区
2. 选择 **买入** 或 **卖出** 标签
3. 点击选择你要交易的选项（显示当前价格）
4. 输入金额
5. 点击交易按钮
6. 在 Petra Wallet 弹窗中确认交易
7. 等待 3-5 秒交易上链
8. 价格图表和交易历史自动更新

### 定价机制

使用 Constant Sum AMM（恒定和做市商）：
- 价格根据各选项的投注池比例实时变化
- 买入时该选项价格上升，卖出时下降
- 平台收取 2% 手续费

### 注意事项

- 最小交易金额：0.01 APT
- 每笔交易需要支付少量 Gas 费（约 0.001 APT）
- 交易后**无法撤回**（链上交易不可逆）
- 价格会随着其他人交易而实时变化

## 创建市场

1. 点击导航栏的 "创建市场"
2. 连接钱包（必须）
3. 填写市场信息：
   - **名称** — 预测主题（1-100 字符）
   - **描述** — 详细规则和结算条件（1-500 字符）
   - **选项** — 2-10 个可能结果
   - **结束时间** — 市场到期时间
   - **分类** — 选择最匹配的类别
   - **结算方式** — 管理员结算 或 Pyth 预言机自动结算
   - **初始流动性** — 最少 1 APT，作为做市资金
4. 点击 "创建市场" 并在钱包中确认

## 查看持仓

点击导航栏的 "持仓" 查看你的投资组合：

- **总投资** — 所有市场的投入总额
- **参与市场数** — 你下注过的市场数量
- **持仓详情** — 每个市场的成本、份额、当前价格、未实现盈亏（P&L）

## 领取奖金

市场结算后，如果你持有获胜选项的份额：

1. 在持仓页面，获胜市场会显示 "领取奖金" 按钮
2. 点击按钮，在钱包中确认交易
3. 奖金自动转入你的钱包

## 理解赔率

赔率反映了市场对某个结果的共识：

- **价格 0.70（70%）** = 多数人看好，收益低但更稳妥
- **价格 0.20（20%）** = 少数人看好，收益高但风险大

价格随交易实时变化。如果更多人买入某个选项，该选项的价格会上升。

## 常见问题

**Q: 最小交易金额多少？**
A: 0.01 APT（1,000,000 Octas）。

**Q: Gas 费是多少？**
A: 通常不到 0.001 APT。测试网免费。

**Q: 可以取消交易吗？**
A: 不可以。链上交易确认后无法撤回，但可以卖出持有的份额。

**Q: 赔率为什么会变？**
A: 赔率根据各选项的池子比例实时计算。其他人交易会改变池子大小，从而改变价格。

**Q: 中奖后怎么领奖？**
A: 在持仓页面点击 "领取奖金" 按钮，手动领取。

**Q: 数据多久更新一次？**
A: 市场列表每 30 秒刷新，市场详情每 10 秒刷新。交易成功后也会立即刷新。

## 故障排除

**钱包连接失败**
- 确认 Petra Wallet 扩展已安装
- 确认钱包网络设置为 Testnet
- 刷新页面重试

**交易失败**
- 检查钱包余额是否足够（交易金额 + Gas）
- 确认市场状态为 "进行中"
- 检查浏览器控制台的错误信息

**页面显示异常**
- 清除浏览器缓存（Cmd+Shift+R 硬刷新）
- 确认使用现代浏览器（Chrome / Firefox / Edge）
